# PIC18F4580 – Timers and Interrupts

## 📌 About the Project
This repository contains my Embedded C practice programs for understanding timers and interrupt handling using the PIC18F4580 microcontroller.

## 🎯 Objectives
- Understand timer operation and configuration.
- Learn interrupt enable bits and interrupt flags.
- Practice writing Interrupt Service Routines (ISRs).
- Explore external and peripheral interrupts.
- Understand polling versus interrupt-driven programming.

## 🛠️ Hardware and Software
- **Microcontroller:** PIC18F4580
- **Programming Language:** Embedded C
- **IDE:** MPLAB (add your version)
- **Simulation:** Proteus Design Suite, where used

## ⏱️ Timer Programs
The repository includes timer-related programs for the timers implemented in the source files.

Topics may include:
- Timer configuration and prescalers
- Timer registers and overflow flags
- Timer-based delays and periodic events

## ⚡ Interrupt Programs
The repository includes programs for the external and peripheral interrupts implemented in the source files.

Topics may include:
- External interrupts: INT0, INT1 and INT2
- Interrupt enable and flag bits
- Interrupt Service Routines (ISRs)
- Timer interrupt handling

## 📂 Source Code
The `.c` files contain the Embedded C implementations. Refer to each file for its specific configuration and functionality.

## 📈 Learning Outcomes
- Practiced configuring microcontroller timer registers.
- Explored interrupt flags and enable bits.
- Improved understanding of interrupt-driven embedded programming.
- Developed debugging skills through coding and simulation.
